# The Grand Horizon - Room Reservation & Management System

A full-stack web application built for hotel room reservations, featuring advanced room management, custom meal selection, and dynamic booking calculations.

##  Tech Stack
* **Backend:** Java Servlets, JSP (JavaServer Pages), JDBC / File-based DAO Pattern
* **Frontend:** HTML5, CSS3, Bootstrap 5, JavaScript
* **Server:** Apache Tomcat 10.1
* **Version Control:** Git & GitHub

##  Key Features
* **Guest Portal:** Browse luxury/standard/normal rooms, check meal availability, and book rooms dynamically.
* **Admin Dashboard:** Manage rooms (create, update, delete, set custom meals), view active bookings with notification badges, and monitor system metrics.
* **Automated Pricing:** Real-time calculation based on room hourly rates and selected meal packages.
* **Role-Based Navigation:** Standardized headers and clean routing for Guests and Admins.
